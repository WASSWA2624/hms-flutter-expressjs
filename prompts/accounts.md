Under the **Invoice** tab, when the **Create** button is clicked, it opens the **Create Invoice** dialog.

In the **Create Invoice** dialog:

* The **Add Item** button should contain only the icon and label.
* The **Items** section should have an appropriate icon next to the label.
* Both should be positioned directly above the items table.

When the **Add Item** button is clicked, open the **Add Item** form dialog with the following layout:

1. **Item Name**
2. **Quantity** and **Unit Price** should appear on the same row.

   * The **Unit Price** field should use the currency input.
   * The default currency should be the organization’s configured default currency.
   * The user should still be able to change the currency if needed.
3. **Description** should appear below the quantity and unit price fields.

The entire form should be fully responsive and adapt properly to different screen sizes.
