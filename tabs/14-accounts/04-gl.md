# Accounts tab — General ledger

## 1. Tab strip

- Label: `General ledger`
- Icon: `Icons.account_balance_outlined`
- Count source: `accountsSectionTabCount` → `accountsGlActivityCountProvider` ?? `AccountsSummary.glActivity` (panel pushes filtered totals when filters active)
- Count tone: `AppTabCountTone.info`
- Deep-link `section`: `gl` (aliases `general-ledger`, `ledger`); may pass `accountId`, `search`
- Tab gate: `AccountsGeneralLedgerAtomPermissions.tab` = entry
- **Omitted when unauthorized**
- Note: `accounts_gl_workspace_page.dart` is a re-export — surface is this in-desk section only

## 2. Search / Filters / Settings / Export / Print / context

Order: **Filters → Settings → Export → Print**

- Search hint: shared
- Filters: present; date filter **enabled** — `Updated date`
- Settings: `accounts_gl_v1`
- Export / table Print: ∩ `evidence:export` — omit when unauthorized (`AccountsGeneralLedgerAtomPermissions.export` / `print`)
- Context trailing: none

## 3. Table

- Row model: `AccountsGlAccount` (facility GL accounts page)
- Row select / Next **GL**: `showAccountsGlDialog` when `canOpenAccountsGlNext` (entry + `hasActivity`)
- Default columns: Account, Debit, Credit, Balance, Next (`GL`)
- Column choices: Type, Period, Updated
- Mobile: trailing `GL` text button when activity

## 4. Advanced filters / search fields

- Text: Period
- Groups: Type (Asset / Liability / Equity / Revenue / Expense), Activity (with / without)
- Date range on updated date

## 5. Primary / secondary / row actions

- Open ledger dialog (row / Next)
- From dialog: Journal create when write; Print ledger packet
