# Accounts tab — General ledger

## 1. Tab strip

- Label: `AccountsStrings.generalLedgerLabel` (`General ledger`)
- Icon: `Icons.account_balance_outlined`
- Count source: `accountsSectionTabCount` → `accountsGlActivityCountProvider` ?? `AccountsSummary.glActivity`; active + narrowed (search / Filters / Updated date) → panel pushes filtered total (`AccountsGlQuery` + local date filter)
- Count tone: `AppTabCountTone.info`
- Deep-link `section`: `gl` (aliases `general-ledger`, `ledger`); may pass `accountId`, `search`
- Tab gate: `AccountsGeneralLedgerAtomPermissions.tab` = entry
- **Omitted when unauthorized**
- Note: `accounts_gl_workspace_page.dart` is a re-export — surface is this in-desk section only

## 2. Search / Filters / Settings / Export / Print / context

Order: **Filters → Settings → Export → Print** (no strip context actions)

- Search hint: shared accounts hint
- Filters: `Filters` → Advanced filters (`commonAdvancedFiltersTitle`)
  - Footer: **Clear filters** → **Apply filters** → **Close**
  - Date filter **enabled** — `Updated date`
- Settings: Table Settings; key `accounts_gl_v1`; exposes defaults + Type / Period / Updated; Reset restores defaults
- Export / table Print: `enableExport` / `enablePrint` + `canExport` / `canPrint` — omit without ∩ `evidence:export` (`AccountsGeneralLedgerAtomPermissions.export` / `print`); Print label `Print`; preview-first `printAccountsListTable`
- Context trailing actions: **none**

## 3. Table

- Row model: `AccountsGlAccount` (facility GL accounts page)
- Row select / Next **GL**: `showAccountsGlDialog` when `canOpenAccountsGlNext` (entry + `hasActivity`); inactive rows are inert
- Default columns (**5**):
  1. Account (alwaysVisible)
  2. Debit
  3. Credit
  4. Balance
  5. Next (`GL`) — alwaysVisible / not exportable; cell omitted without activity
- Column choices (Settings extras): Type, Period, Updated
- Mobile: caption type; trailing `GL` text button when activity

## 4. Advanced filters / search fields

- Text: Period
- Groups: Type (Asset / Liability / Equity / Revenue / Expense), Activity (with / without)
- Date range on updated date (client-side; badge uses filtered length)
- Same panel filter model drives table rows and active tab badge

## 5. Primary / secondary / row actions

- Open ledger dialog (row / Next) when activity
- From dialog: Journal create when write; Print ledger packet
