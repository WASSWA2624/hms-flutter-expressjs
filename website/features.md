// This web app is the product and documentation site for the HOSSPI Hospital Management System (app.hosspi.com). It advertises the system to hospitals evaluating it and documents how it works for the people using it. Static, multilingual, no database.


- **Product Page**: Hero with the HOSSPI mark, headline figures, value propositions, coverage by department, care journeys, staff roles, packages, roadmap, and FAQ.
- **Guide**: Getting started, what the system covers, how a patient moves through it, what each role can do, choosing a package, and frequently asked questions.
- **App Access**: Prominent links to the live HOSSPI HMS application on web, Android, iOS, desktop, and Linux.
- **About Page**: Company story, mission and vision, the commitments behind the software, and an enquiry form.
- **Contact Page**: Contact channels (email, phone, messaging, location), common enquiry types, and a validated contact form.
- **Icon System**: Hand-drawn inline SVG set covering clinical, platform, finance and interface glyphs, inheriting text colour in both themes.
- **Contact Form Delivery**: Submissions are emailed via SMTP, with an optional confirmation email to the sender.
- **Brand Alignment**: Palette and logo taken from the HMS application itself, so the site and the product read as one brand.
- **Responsive Navigation**: Inline horizontal links on desktop, hamburger menu on tablet and mobile.
- **Minimal Footer**: Copyright, main navigation links, and a link to the app.
- **Localization**: Site chrome supports 9 languages with automatic locale detection and RTL layout for Arabic. Product content is English-only.
- **Theming**: Dark and light mode with system preference detection and a manual toggle.
- **SEO**: Per-page metadata, social share card, canonical URLs, sitemap, and structured data for the software and its FAQ.
