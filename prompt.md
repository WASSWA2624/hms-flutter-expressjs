In the OPD module, several improvements are needed across patient workflow actions when a patient is waiting for doctor review.

The actions section (updates, consultation, billing) should be fully functional and consistent. The billing/consultation form needs to clearly show the service cost breakdown: required amount, amount paid, and remaining balance. This should be integrated and updated whenever billing changes occur.

The diagnosis module should be improved so that it supports real-time updates. Searching for diagnoses should be fast and responsive, and any newly added diagnosis should immediately reflect across the system without delay.

Lab requests also need real-time behavior for both individual tests and lab panels. Adding a test or panel should instantly update the request list, and search within labs should be real-time as well.

Radiology requests require a major UX and structural review. The modality and body region selection is currently present, but the body region representation is not intuitive. Icons for regions like abdomen, pelvis, acetabulum, ankle, etc., should be more descriptive and clinically meaningful. Laterality options also need to be expanded to fully support left, right, bilateral, and oblique views.

The imaging catalog should dynamically filter based on selected modality and body region, ensuring users only see relevant options. The radiology request form should be standardized into a single global component/dialog used consistently across the app. It must be fast, seamless, and easy to use, with a clean and informative layout. Clinical notes input should also be included and well integrated.

The prescription display should be improved to present medication details in a clear, human-readable format. This includes drug name, quantity, units, dose, dose units, route, and frequency, structured so both medical and non-medical users can understand it easily.

The referral form needs layout fixes and better formatting. It currently has bottom overflow issues and requires a cleaner, more structured design. The same applies to the procedure recording form, which should be made more readable, easier to use, and more user-friendly for quick selection and entry.

Finally, all OPD action components should be reviewed holistically for consistency, usability, and performance, since they are widely used across the application. The print summary functionality can be addressed separately later.
