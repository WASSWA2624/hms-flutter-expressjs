# P005 WebSocket Transport
Provide realtime delivery without leaking transport concerns into domain services.

## Transport

- Bootstrap the WebSocket server and gateway.
- Connections must authenticate under the same rules as HTTP requests.
- Subscriptions must be scoped by tenant, facility, role, entitlement, and module.
- Shared emit helpers should let services publish domain events without transport coupling.

## Acceptance

- WebSocket authorization must match backend access rules.
- Event names and payloads must remain stable and use `snake_case`.
- Services must publish updates without bypassing module boundaries.
