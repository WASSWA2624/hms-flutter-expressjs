# P004 Backend Internationalization
Prepare system-generated backend text for safe, deterministic localization.

## Requirements

- Ship a stable English (`en`) catalog and locale-resolution helpers.
- Responses and problem details must use translation-ready system messages.
- Add locale-aware date, time, and number helpers where backend formatting is required.
- User-entered text must not be translated or otherwise altered.

## Acceptance

- Locale resolution must be deterministic.
- All system-generated text should be localization-ready while preserving user content exactly.
